# Local Network Security Assessment Tool

## Overview
This project was created as a learning exercise to help me understand
the basics of network security using Linux. It focuses on identifying
open ports and running services on a system in a safe and ethical way.

## Tools Used
- Linux (Ubuntu)
- Nmap
- Bash scripting

## Ethical Disclaimer
This project is strictly for educational purposes.
All scans were carried out on systems I own or have permission to test,
such as localhost.
